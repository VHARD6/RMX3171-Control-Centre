# Security Policy

## Supported Versions

Currently, this repository does not have a formal release version schedule. As a public release, security updates will be applied to the main branch as issues are responsibly reported and resolved.

## Reporting a Vulnerability

Please use GitHub's private vulnerability reporting mechanism if enabled for this repository. If this mechanism is unavailable, please open an issue describing the security concern broadly, and maintainers will provide a secure channel for the detailed disclosure.

Do not post sensitive exploits or vulnerable personal device dumps in public issues.
